Studio — Windows-Installer

Beide Programme (HD60 und Wave Link Linux / Spurwerk) sind für Nobara/Fedora (Linux) gebaut.

Dieser Installer lässt dich wählen, welche Programme als Dateipaket nach
%LOCALAPPDATA%\Studio kopiert werden — zum Übertragen auf einen Linux-Rechner
oder zur Nutzung in einer Linux-VM / unter WSL2 (soweit möglich).

Für die echte Installation bitte den Linux-Installer von GitHub Releases nutzen:
https://github.com/Bavarian4736/studio/releases

Unsigned Build: Windows SmartScreen kann warnen — „Weitere Informationen“ → „Trotzdem ausführen“.
